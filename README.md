# 春秋蝉 2.0

中文、手机优先、无需登录的纯静态生活记录 Web App。没有后端、外部字体、统计脚本或第三方网络依赖。

## 上传到已经创建的 chunqiu-chan 仓库

1. 将压缩包解压，找到 `index.html`、`styles.css`、`app.js` 等文件。
2. 打开 GitHub 上的 `chunqiu-chan` 仓库。空仓库点击 **uploading an existing file**；已有文件的仓库点击 **Add file → Upload files**。
3. 把解压后的全部网站文件拖入上传区域，然后点击 **Commit changes**。应让 `index.html` 直接位于仓库根目录，不要把 ZIP 上传，也不要多套一层文件夹。
4. 打开仓库 **Settings → Pages**。
5. 在 **Build and deployment** 中，Source 选择 **Deploy from a branch**，Branch 选择 **main**，文件夹选择 **/(root)**，点击 **Save**。如果仓库默认分支名称不是 main，选择实际包含这些文件的分支。
6. 等待 GitHub 完成发布，在 Pages 页面打开给出的地址。典型格式是 `https://你的用户名.github.io/chunqiu-chan/`。
7. 在手机浏览器打开这个地址。iPhone 可通过 Safari 的“分享 → 添加到主屏幕”保存入口。SVG 图标和安装提示的支持因浏览器而异，但网页功能不依赖安装。

发布源设置参考：[GitHub 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 文件清单

| 文件 | 用途 |
| --- | --- |
| index.html | 网站入口 |
| styles.css | 手机和桌面布局 |
| app.js | 所有交互及本地存档 |
| manifest.webmanifest | 应用名称、图标、启动地址 |
| icon.svg | 矢量图标，无二进制资源 |
| sw.js | 在线优先、离线回退缓存 |
| .nojekyll | 让 GitHub Pages 直接发布静态文件 |
| README.md | 本说明 |

无需构建，无需 npm，无需数据库或密钥。所有资源使用相对路径，支持 `/chunqiu-chan/` 子路径。使用网址访问可启用离线缓存；直接双击本地 HTML 仅适合临时查看，各浏览器对本地文件的存储规则不同，且无法注册离线服务。

## 五个页面

- **今日**：Day X/90、新手期进度、基地等级、累计经验、10 项任务、Mind 三行日志。
- **生长**：英语、身体、职业、经济自主、Mind 五条科技树，每条独立累积。
- **记录**：职业探索、财务收支、每日档案。职业与财务支持选择过去日期补录；日志可回看和修改。
- **复盘**：周一到周日的行动统计，三项周复盘，完成过去一周的结算。
- **设置**：模式、经验提示、旅程开始日期、自定义目标、完整备份导入导出。

## 行动与成长规则

- 每天 10 项：英语、跑步/快走、户外步行、公考、三个短视频禁区、职业探索、财务记录、Mind 三行日志。
- 三个禁区的初始建议是起床后、学习/工作时、睡前不刷短视频；可在设置修改。时长同样是可调整的建议，并非从访谈中确认的硬性标准。
- 普通模式每项 10 XP，低功耗模式每项 5 XP。同一项任务同一天只计一次，完成时保存当时的目标与模式。切换模式不追加经验，撤销会移除该次经验。
- 职业探索、财务、Mind 任务由记录自动完成。财务可确认“今日无收支”；填写完整三行日志后完成 Mind。删除最后一条对应记录会撤销任务经验。
- 基地每 200 XP 升一级，科技树每 100 XP 升一级。周结算奖励仅计入基地。没有断签扣分，等级无上限。
- 周日结束后，可给刚结束的一周结算；必须已有至少一个完成任务，并保存完整的三项复盘。每周只领取一次 50 XP。修改已结算复盘不再发奖；结算奖励作为已完成的历史结算保留。
- Day X 使用设备本地日历，开始当天为 Day 1。进度到 90 天后显示完成，Day 91、Day 101 等继续增长，任务、经验与记录不重置。
- 首页可撤销当天的手动任务。每日档案中的历史任务只读，避免无意更改；记录类任务随对应内容更新。
- 表单需要点击保存。当前页面会保留切换页面或勾选任务前的未保存草稿，关闭页面前会尝试提醒；未保存草稿不作为正式备份内容。

## 存档一定要看

这里的“永久延续”指应用没有 90 天清零、历史过期或自动删除规则，不等于浏览器存储永远不会丢失。

数据保存在当前浏览器的网站 localStorage，使用键 `chunqiu-chan-v2`。刷新或正常关闭后可继续使用；清除站点数据、隐私浏览、浏览器自动清理、更换设备、浏览器或网址可能使原存档不可见。**建议每周在设置中导出一次备份。**

换设备：先在旧设备导出 JSON 备份，再在新设备打开网站并导入。导入会先校验并显示内容概况，确认后替换当前存档；不会合并两个设备的数据。请先导出新设备已有存档，以免被覆盖。

备份文件包含个人日志与财务记录，只需自行保管，**不要随网站文件上传到公共 GitHub 仓库**。本交付包不含个人存档或测试数据。

存储写入失败时页面会给出提示，此时请保持页面打开并导出备份；损坏的旧存档不会被自动覆盖，可在设置导出原始内容并导入有效备份。导入文件上限为 20 MB。没有跨设备自动同步；同一浏览器建议仅开一个标签页录入。

## 离线与更新

在 HTTPS 网站成功在线打开并完成缓存后，可离线再次打开并记录。离线缓存与本地记录相互独立；清理网站存储可能同时清除两者。首次离线打开不保证可用。

更新网站时替换对应文件，并修改 `sw.js` 内的版本后缀。保持网站地址与本地存储键不变，可保留原记录。发布前先导出一份备份。网站采用在线优先获取页面，网络不可用时使用缓存。
